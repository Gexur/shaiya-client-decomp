# Historical recovery notes

`client-recovery.md` and `graphics-recovery.md` preserve the client documentation
from the original `shaiya` workspace unchanged. They record earlier recovery and
validation work, including its limits. Their Python/mise commands, relative
evidence links, tool paths and object counts describe that earlier workspace;
those tools and evidence artifacts are not part of this standalone project.

Use the [project README](../../README.md) for an overview and the
[build guide](../building.md) for current Zig build and run instructions.
Historical validation reports are not a claim that the standalone build has
repeated all of those runtime checks.
